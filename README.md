# YouTube Browser

A simple and clean YouTube search browser built with Node.js, Express, HTML, CSS, and JavaScript.  
Users can search directly on YouTube using a minimal interface with smooth background animation.

---

# Features

- Search YouTube instantly  
- Enter key support  
- Opens YouTube results in a new tab  
- Clean UI with animated background  
- Responsive design  
- Docker support  
- Deployed on Render  

---

# Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express.js  
- Containerization: Docker  
- Hosting: Render
